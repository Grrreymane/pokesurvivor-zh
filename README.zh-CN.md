# 宝可梦幸存者 · 简体中文版

基于 [JPTER78 / PokéSurvivor](https://github.com/JPTER78/pokesurvivor) 的本地中文修改版，保留原版 Canvas 游戏引擎、像素地图、966 只宝可梦、招式升级、裂隙首领、收藏、扭蛋、强化、任务与成就。

## 启动

在线试玩：**https://grrreymane.github.io/pokesurvivor-zh/**。无需安装或登录，手机请横屏。首次点击页面后会播放音乐。线上试玩与本机预览的存档相互独立。

双击 `启动中文版.cmd`，或在项目目录执行 `npm start`，打开 **http://127.0.0.1:4173/**。

无需安装依赖。没有 Node.js 时也可双击 `index.html`；建议固定使用本机地址，避免浏览器对本地文件的限制。

打开后自动继续本地存档；首次进入会直接开始性格测试。没有登录或注册步骤。保存内容包括伙伴、收藏、货币、强化与结算成绩，正在进行的战斗不会原地续玩。存档在当前浏览器的本地存储中；更换浏览器或访问地址会使用不同的存档空间，清除网站数据会丢失存档。设置 → 存档可查看保存状态或重置当前冒险进度。

## 操作

| 按键 | 作用 |
| --- | --- |
| WASD / 方向键 | 移动 |
| 1—4 | 切换当前招式，攻击自动进行 |
| Q / E | 上一个 / 下一个招式 |
| Esc / P | 暂停 |
| 升级时 1—3 | 选择奖励 |

手机横屏，触摸拖动移动，点击招式图标切换。更多说明见 `guide-zh.html`。

## 中文化与维护

- 默认简体中文；设置 → 画面 → 语言可切换英语或西班牙语。
- 界面词典在 `js/data/lang-zh*.js`，宝可梦中文名在 `js/data/pokemon-zh.js`。
- `dev.html` 为开发入口；修改源码后执行 `npm run build` 更新首页与脚本。
- 网页通过 GitHub Pages 从 `main` 分支根目录发布：构建、测试后提交并推送，Pages 会自动部署更新。
- `npm test` 检查翻译覆盖、动态文案、语言隔离与本地存档。
- 本版本为单机版，已移除登录、注册、好友与全球排行入口，保留此前的本地存档。
- 好友、排行榜、组队房间和邀请面板暂时隐藏；组队成就及组队战绩也不再显示，保留单人最佳成绩。
- 背景音乐：宝可梦绿宝石（素材来源见 `assets/music/README.txt`）；音效保留原游戏。
- 每张地图各有 4 首音乐，按本局时间每分钟轮换；首领、裂隙与审判音乐优先，暂停不推进轮换。地图仍每四分钟切换。
  - 森林：101 号道路 → 104 号道路 → 橙华森林 → 119 号道路。
  - 洞窟：起源洞窟／流星瀑布 → 布告石室 → 弃船 → 冠军之路。
  - 火山：烟囱山 → 113 号道路 → 熔岩队／海洋队基地 → 111 号道路。
